4. Registro y Clasificación de Incidencias
Nivel de Severidad Criterio de Impacto Impacto en Salida
Bloqueante (Severidad 1) El sistema se cae, produce pérdida de datos o bloquea por completo el flujo de venta/operación sin alternativa manual. Impide Producción
Alta (Severidad 2) Falla funcional importante de una regla de negocio clave, pero existen alternativas temporales de operación. Impide Producción
Media (Severidad 3) Error menor en interfaz, problemas de ordenamiento, filtros o validaciones no críticas. Garantía / Parche
Baja / Mejora (Severidad 4) Ajustes de diseño visual, textos, cambios de color o sugerencias que no formaban parte del alcance original. Backlog Futuro
